# Notes

Backend einer Notizen-App auf Basis von Django und Django REST Framework (Projekt der Developer Akademie).

## Aufbau

Der Code liegt im Ordner `da_notes_backend`. Eine ausführliche Anleitung steht in [da_notes_backend/README.md](da_notes_backend/README.md).

## Technologien

Python · Django · Django REST Framework

## Schnellstart

1. Repository klonen: `git clone https://github.com/KonstantinFenzlein/Notes.git`
2. In den Ordner wechseln: `cd Notes/da_notes_backend`
3. Abhängigkeiten installieren: `pip install -r requirements.txt`
4. Umgebungsvariablen anhand von `.env.example` anlegen
5. Migrationen ausführen und starten: `python manage.py migrate` und `python manage.py runserver`
